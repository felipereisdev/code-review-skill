# Python / Django / FastAPI / Flask — Code Review Checklist

- **Type hints**: all function signatures use type hints; `mypy` or `pyright` passes without errors
- **Async correctness**: `async def` used only where truly async; blocking I/O not called from async context
- **ORM queries**: Django ORM / SQLAlchemy used correctly; `select_related`/`prefetch_related` used to avoid N+1
- **Pydantic / serializers**: input validated via Pydantic models (FastAPI) or DRF serializers (Django); no raw dict access from request
- **Exception handling**: specific exceptions caught, not bare `except:`; exceptions not swallowed silently
- **Settings management**: secrets and config loaded from environment via `django-environ`, `python-decouple`, or Pydantic `BaseSettings`; not hardcoded
- **Migrations** *(Django)*: migrations generated and reviewed; no raw SQL in application code unless necessary

## Precedents

- **ORMs and DB-API parameters bind values**: Django ORM filters, SQLAlchemy query expressions and `cursor.execute(sql, params)` send values as query parameters. Do not report SQL injection for values passed that way. **Exception:** Django `raw()`, `extra()` and `RawSQL()` or SQLAlchemy `text()` with formatted strings, and SQL text built with f-strings, `%` or `.format()` before it reaches `execute()`.
- **Django and Flask templates autoescape**: Django templates, and Flask's Jinja2 templates named `.html`, `.htm`, `.xml` or `.xhtml`, escape ordinary untrusted string values rendered with `{{ value }}`, which makes them safe in HTML text and in quoted, non-executable attribute values. Do not report XSS for such string values rendered that way. **Exception:** the `|safe` filter, `mark_safe()`, `Markup()`, Flask/Jinja objects implementing `__html__()`, including custom or helper-produced ones, whose result MarkupSafe treats as trusted HTML without escaping, so the code that produces it must establish its safety, `{% autoescape off %}`, Flask templates with other extensions such as `.txt` or `.j2`, a bare `jinja2.Environment()`, which does not autoescape by default, user-controlled URLs in `href`, `src` or `action`, where escaping does not stop a `javascript:` URL, unquoted attribute values (`<input value={{ value }}>`), where a space starts a new attribute such as `onmouseover`, and values inside `<script>` blocks or event-handler attributes, which need `json_script` or `|tojson` instead.
- **Django checks CSRF tokens on unsafe methods**: `CsrfViewMiddleware`, on by default, rejects requests with any method other than `GET`, `HEAD`, `OPTIONS` or `TRACE` that lack a valid token, and it does not check those four safe methods. Do not report missing CSRF protection on an unsafe-method Django view that the middleware covers. **Exception:** views decorated with `@csrf_exempt`, projects that removed the middleware from `MIDDLEWARE`, Django REST Framework views, which enforce CSRF only with `SessionAuthentication`, and views that change state on `GET`, `HEAD`, `OPTIONS` or `TRACE`, which the middleware never checks.
- **FastAPI validates typed parameters**: path, query and body parameters declared with Pydantic models or type annotations are validated before the handler runs, and invalid input gets a 422 response. Do not report missing type validation for them. **Exception:** parameters typed as `dict` or `Any`, bodies read from the raw `Request`, and constraints the type does not state, such as ranges, lengths or formats not declared with `Field()` or `Annotated`.
